# 背景と前提

## イベントの概要

**プロトフェス** — 近畿大学経営学部 布施ゼミが運営に関わる、プロトタイプ展示イベント。
出展者が試作品を展示し、来場者が会場を回遊して各ブースを訪問する。

### 第3回（2025年）

| 項目 | 内容 |
|---|---|
| 開催日 | 2025年10月10日（金）・11日（土）の**2日間** |
| 出展ブース数 | **40**（番号は①〜㊶。21番と42番は欠番） |
| アプリ登録者 | **302名**（2日間の延べ） |
| 総チェックイン | **2,141件** |
| アプリ | ビンゴラリー形式。4×4の16マスに推薦ブースを配置 |

### 第4回（2026年）

| 項目 | 内容 |
|---|---|
| 開催日 | **金曜1日のみ** |
| 出展ブース数 | 40（想定。去年実績と一致） |
| 参加者見積もり | 150〜200名 |

## 去年と今年の差分が分析に与える影響

### 開催日数が 2日 → 1日 に変わる

これが最も重要な差分であり、**分析設計の根幹に関わる**。

#### 影響1: 規模の比較には日別分解が必須

302名は**2日間の延べ登録者数**である。今年の見積もり「150〜200名」と直接比較してはならない。
仮に初日150名・2日目150名であれば、今年の見積もりはむしろ妥当ということになる。

**したがって、最初に算出すべきは「日別の登録者数・チェックイン数」である。**
これが出るまで、今年の規模見積もりの妥当性は判定できない。

#### 影響2: 初日（金曜）が主分析対象になる

今年は金曜のみの開催であるため、**去年の初日（10/10 金）が最も比較可能性の高いデータ**である。
土曜は来場者層が異なる（一般来場者・家族連れの比率が上がると予想される）ため、
土曜のデータをそのまま今年の予測に使うと誤る可能性がある。

**原則: 主分析は初日（金）。土曜は参考値・頑健性確認に用いる。**

#### 影響3: ただし初日にはクールタイム変更の交絡がある

初日にはアプリのクールタイム設定が変更されている（詳細は
[confounders.md](../04-analysis/confounders.md)）。
そのため「主分析は初日」という原則と、「クールタイム値が一定なのは土曜」という事情が衝突する。

**この衝突は指標ごとに解決する。**
- チェックイン間隔に依存する指標（E-2 / E-3）→ 土曜を主とする
- それ以外 → 初日を主とする

この使い分けは [metrics-catalog.md](../04-analysis/metrics-catalog.md) に指標ごとに明記する。

#### 影響4: 両日参加者の存在

同一ユーザーが両日参加している可能性がある。
滞在時間を「最終チェックイン − 初回チェックイン」で算出すると、
両日参加者は**24時間超**になり分布が壊れる。

**対策: 分析単位は「ユーザー」ではなく「ユーザー × 日」とする。**
両日参加者が何名いたかは、独立した知見として別途カウントする。

## 用語

| 用語 | 定義 |
|---|---|
| チェックイン | 来場者がブースのQRコードを読み取り、訪問を記録する行為 |
| 滞在時間 | 入退場時刻の記録がないため、**最終チェックイン − 初回チェックイン**で代用する |
| 単発訪問者 | チェックインが1件のみの参加者。滞在時間が定義上 0 になる |
| 訪問ブース数 | ユニークなブースIDの件数（去年の仕様上、チェックイン総数と一致する） |
| 推薦マス | ビンゴカード16マスのうち、協調フィルタリングで選ばれたマス（`is_recommendation = true`） |
