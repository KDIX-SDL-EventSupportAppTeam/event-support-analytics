# 可視化仕様

## 原則

**「見て面白い図」ではなく「見た結果として設計が変わる図」だけを作る。**

各図は必ず、[decision-criteria.md](../01-context/decision-criteria.md) の
5つの判断のいずれかに紐づく。紐づかない図は作らない。

## 判断と図の対応

| 判断 | 決め手になる図 |
|---|---|
| 1. 参加者の典型像 | **A-1 ヒストグラム + C-3 散布図** |
| 2. データ件数規模 | C-2（数値） × F-1（日別） |
| 3. 推薦が届く対象 | **C-1 ヒストグラム（0件から）** |
| 4. 偏り対策のコスト | D-1 横棒グラフ + D-2（数値） |
| 5. データが溜まるタイミング | **B-2 と B-3 の重ね描き** |

---

## 個別仕様

### A-1: 滞在時間ヒストグラム

- 横軸: 滞在時間（30分刻み）
- 縦軸: **人数**（割合ではない）
- **A-3 の値（30分未満の割合）を図中に数値として直接書き込む**

数値の書き込みは必須。最重要指標をヒストグラムから目測させてはならない。

- 単発訪問者は除外し、除外した人数を注記する
- 最上位ビンは「3時間以上」としてまとめる
- 分布が二峰性を示す場合、その旨を注記する（判断1が変わる）

### B-2 / B-3: 時間帯別の流れ

**必ず同一の図に重ねて描く。** 別々のグラフにしてはならない。

- 横軸: 時刻（JST、30分刻み）
- 縦軸左: 新規参加者数（B-2、棒グラフ）
- 縦軸右: 同時滞在人数（B-3、折れ線）

別々に描くと「新規流入のピーク」と「滞在人数のピーク」のズレが読み取れない。
**このズレこそが判断5の対象である。**

必須の注記:
- B-3 は初回チェックイン前・最終チェックイン後が不可視であること
- **推薦フォールバックが解除された時刻（実績者20人到達）を縦線で示す**

### C-1: 訪問ブース数ヒストグラム

- 横軸: 訪問ブース数（1件刻み）。**必ず0から開始**
- 縦軸: 人数

0件のバーが最も重要な情報である
（[unavailable-data.md](../02-data-source/unavailable-data.md)）。
1件以上に絞ってはならない。

- ビンゴカード未生成者は0件のバーの内数として色分けする

### C-3: 滞在時間 × 訪問ブース数 散布図

- 横軸: 滞在時間（分）
- 縦軸: 訪問ブース数
- **回帰直線を1本引き、傾き（ブース/時間）を図中に明記する**

この傾きが、今年の規模見積もりで最も再利用される数字である。

- 単発訪問者（滞在時間0）は回帰から除外する。原点付近に張り付き傾きを歪める
- 除外した点は、グレーで参考表示してもよい

### D-1: ブース別訪問者数

- **横棒グラフ**（縦棒にしない）
- 訪問者数の降順に並べる
- ラベルは `booth_short`（短縮名）を使う

縦棒にするとブース名が読めない。
ブース名には60文字を超えるものがあるため、短縮名の準備が前提
（[intermediate-tables.md](../04-analysis/intermediate-tables.md)）。

- 上位20%（上位8ブース）を色分けし、D-3 の値を図中に明記する

### E-1: 初回訪問ブースの分布

- 横棒グラフ、降順
- 上位10ブースに絞ってよい（全体はD-1で見えるため）
- 集中度（上位3ブースの占有率）を数値で併記する

### クールタイムの床（交絡確認用）

**分析結果の図ではなく、前提確認のための図。**

- 横軸: 時刻（JST、30分刻み）
- 縦軸: チェックイン間隔（秒、対数軸）
- 描くもの: ビンごとの**最小値**と**5パーセンタイル**

階段状の段差がクールタイム変更時刻を示す。
[confounders.md](../04-analysis/confounders.md) 交絡1 の手順。

この図は最初に作り、他のすべての分析の前提として参照する。

## 共通ルール

### 日別の扱い

**両日の結果を必ず併記する。** 片方だけを示すと、読者は差の存在に気づけない。

主分析日（金／土）の使い分けは
[metrics-catalog.md](../04-analysis/metrics-catalog.md) の指標ごとの指定に従う。
図には**どちらの日のデータか**を必ずタイトルに明記する。

### 時刻の表示

すべて **JST** で表示し、軸ラベルに「(JST)」と明記する。
UTC のまま描くことは禁止。

### 数値の併記

判断に直結する数値は、図から目測させず**図中に直接書き込む**。

対象:
- A-1 → 30分未満の割合
- C-3 → 回帰の傾き
- D-1 → 上位20%の占有率、最多／最少の倍率
- E-1 → 上位3ブースの占有率

### 個人が特定されうる粒度の禁止

該当者が1〜2名になる集計は図にしない
（[privacy-policy.md](../03-extraction/privacy-policy.md)）。

特に F-2（属性別）で、年代 × 性別 × ジャンルのような
多重クロス集計を行う際に注意する。

### 出力形式

- 形式: PNG（レポート添付用）および HTML（対話的に確認する場合）
- 出力先: `output/figures/`
- **`output/` はコミットしてよい**（集計済みで個人情報を含まないため）

ただし図の元になる CSV（`data/tables/`）はコミットしない。
