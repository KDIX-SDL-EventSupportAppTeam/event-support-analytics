# Git 運用

## ブランチ

| ブランチ | 役割 |
|---|---|
| `main` | 本番。**直接触らない** |
| `develop` | 統合先。作業ブランチはここへマージする |
| 作業ブランチ | `feat/` `fix/` `docs/` `test/` `refactor/` + 短い説明 |

## PR

- **作業ブランチ → `develop` へ PR を作成する。** これが既定の流れ
- **`develop` → `main` の PR は、明示的に指示されたときだけ作成する**
- タイトル・本文・コメントはすべて**日本語**
- 1 PR = 1 目的。レビューできない大きさにしない

## コミット

- メッセージは**日本語**
- 1 コミット = 1 意図。後から追いやすい細かい粒度にする
- 形式: `種別(範囲): 要約`（例: `feat(bingo): 段階解放のライン判定を追加`）
- 種別: `feat` / `fix` / `docs` / `test` / `refactor` / `chore` / `merge`

## やらないこと

- `main` への直接コミット・直接プッシュ
- `--no-verify` でのフック回避、`--force` プッシュ
- 秘密情報のコミット（`.env` は `.gitignore` 済み）
